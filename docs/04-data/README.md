# Legacy Data & Phase History Index (Phases 6–32)

**Status:** ACTIVE — legacy phase-history index
**Scope:** Historical Phase 6–32 data-population, capability, and provenance-engine records
**Authority:** PHASE RECORD / REFERENCE index (historical evidence; does not supersede
current authoritative architecture, data model, or API documentation)
**Last verified:** 2026-08-13

This directory holds the earliest phase-history records for Project Berean, from the
initial Genesis 1–11 controlled population (Phase 6) through cross-domain scholarly
research generalization (Phase 32). For the canonical phase-history index covering both
this directory and later phases, see [`../phases/README.md`](../phases/README.md).

Reference material that is not a phase record also lives here for historical/traceability
reasons: [`DATA_POLICY.md`](./DATA_POLICY.md), [`GENESIS_1_1-5_SLICE.md`](./GENESIS_1_1-5_SLICE.md),
[`POPULATION_SPECIFICATION.md`](./POPULATION_SPECIFICATION.md), and
[`STEPBIBLE_ACQUISITION_REPORT.md`](./STEPBIBLE_ACQUISITION_REPORT.md).
`DATA_POLICY.md` remains here for continuity with the legacy data-population records; if Project
Berean later establishes a broader policy hierarchy, it can be moved with redirects/cross-links
instead of silently changing historical references.
