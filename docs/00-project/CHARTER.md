# Project Berean Charter

## Mission

Build a durable, provenance-aware knowledge foundation that preserves the distinction between what sources contain, what evidence can be extracted from them, what claims are asserted, and what knowledge relationships can be derived or represented.

## Principles

1. **Provenance first** — Every source-grounded assertion should be traceable to its origin.
2. **Claims are not automatically truth** — A claim is an assertion to be evaluated, not a declaration that the proposition is universally true.
3. **Evidence is source-grounded** — Evidence must retain enough provenance to identify the source record and source location from which it was derived.
4. **Canonical entities are distinct from source identities** — Different sources may refer to the same conceptual entity differently. Reconciliation must preserve both identities.
5. **Competing claims coexist** — Contradictory claims must not be resolved by overwriting one claim with another.
6. **Derived knowledge is distinguishable** — A proposition inferred from source observations must not be represented as though the source explicitly stated it.
7. **The knowledge model is separate from ingestion mechanics** — Source-specific import logic should not contaminate the canonical model.
8. **Prefer explicit semantics** — If a relationship matters to the meaning of the knowledge system, represent it explicitly rather than hiding it in free text.
9. **Validate before scaling** — Genesis 1–11 is a regression/stress test. Architectural weaknesses should be corrected before large-scale ingestion.
10. **Keep the core focused** — Do not introduce sovereign geography, residency, security classification, or unrelated infrastructure concerns into Berean.
